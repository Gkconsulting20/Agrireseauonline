# PARTIE 1 : COMPRENDRE LE PRODUIT

## Qu'est-ce que AgriRéseau Pro ?

AgriRéseau Pro est une **plateforme numérique** qui connecte tous les acteurs de la chaîne agricole au Togo :

- Producteurs (agriculteurs)
- Éleveurs
- Transporteurs
- Transformateurs
- Grossistes
- Détaillants
- Institutions

### Problèmes résolus

| Problème actuel | Solution AgriRéseau Pro |
|-----------------|-------------------------|
| Difficile de trouver des acheteurs | Annuaire visible par tous |
| Pas de visibilité sur les prix | Comparaison des offres |
| Gestion des dépenses sur papier | Budgets numériques |
| Pas de suivi des coûts | Calcul automatique du coût de revient |
| Transport difficile à organiser | Offres/demandes de logistique |

# PARTIE 3 : VOTRE CODE COMMERCIAL

## Comment fonctionne votre code ?

Chaque commercial a un **code unique** au format :
```
COM-VOTRENOM-XXXX
Exemple : COM-KOFFI-7834
```

### Où trouver votre code ?

1. Connectez-vous à AgriRéseau Pro
2. Votre code apparaît dans l'onglet "Performance"
3. Cliquez sur "Copier" pour le partager facilement

### Comment ça marche ?

1. Vous donnez votre code à un prospect
2. Il s'inscrit avec votre code (champ "Code commercial")
3. Il devient votre "recrue"
4. Vous voyez ses statistiques dans votre dashboard
5. Vous gagnez une commission quand il passe Premium

3. Remplir les informations :
   - Nom complet
   - Email OU téléphone
   - Mot de passe
   - Région
   - Rôle (producteur, éleveur, etc.)
   - **CODE COMMERCIAL : [VOTRE CODE]** ← IMPORTANT !
4. Accepter les conditions
5. Créer le compte

**IMPORTANT : Assurez-vous que votre code est bien entré !**

# PARTIE 7 : FAQ TECHNIQUE

## Comment le client paie Premium ?

1. Dans l'application > "Abonnement"
2. Cliquer "Passer Premium"
3. Choisir le mode de paiement :
   - T-Money
   - Flooz
   - Carte bancaire (Visa/MasterCard)
4. Suivre les instructions de paiement
5. Premium activé automatiquement !

## Le client a oublié son mot de passe ?

1. Sur la page de connexion
2. Cliquer "Mot de passe oublié"
3. Entrer son email ou téléphone
4. Recevoir le lien de réinitialisation

## L'application ne charge pas ?

Vérifier :
- Connexion internet active
- Vider le cache du navigateur (Ctrl+Shift+R)
- Essayer un autre navigateur

## Le paiement a échoué ?

- Vérifier le solde du compte mobile money
- Réessayer après quelques minutes
- Contacter le support si le problème persiste
