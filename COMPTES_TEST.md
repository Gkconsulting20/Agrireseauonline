## 🧪 **Test Rapide (5 minutes)**

### **Avec le compte utilisateur simple** :

1. **Connexion** :
   - Connectez-vous avec `test@agrireseau.tg` / `Test2025`

2. **Créer un acteur** :
   - Onglet "Acteurs" → "+ Ajouter"
   - Nom : "Ma Ferme de Maïs"
   - Rôle : producteur
   - Région : Plateaux
   - Produits : Maïs;Soja
   - → Enregistrer

3. **Créer un budget avec cycle de production** :
   - Onglet "Budget" → "+ Nouveau budget"
   - Activité : "Production Maïs 2025"
   - Acteur : Ma Ferme de Maïs
   - Date de début : Aujourd'hui
   - **Cycle (jours) : 90**
   - Produit : Maïs
   - Quantité : 5000 kg
   - Prix : 450 FCFA/kg
   - → Créer

4. **Vérifier l'affichage** :
   - Retourner dans "Acteurs"
   - Vous verrez :
   ```
   📅 En production: Maïs: Dispo. estimée [date] (5000 kg)
   ```

5. **Simuler la récolte** :
   - Budget → Cliquer sur votre budget
   - Section "Récolte" → Entrer 4800 kg
   - → Enregistrer

6. **Voir le changement** :
   - Retourner dans "Acteurs"
   - Maintenant :
   ```
   📦 Disponible: Maïs: 4800 kg
   ```
